# Mongering Asians

Gallery-style searchable catalog of Ghost Cash affiliate ad tools:

- Free Hosted Galleries (FHG)
- Content ZIP picture sets
- Video downloads

All outbound links use the provided tracking IDs.

## Live site

After enabling GitHub Pages (Settings → Pages → Deploy from branch `main` / root), the site will be available at:

**https://livecamrooms.github.io/mongering-asians/**

## Notes

- Thumbnails are loaded from the original network.
- Full content ZIP extraction is not included (size & copyright). The catalog links to the official download/gallery pages instead.
- Data is static (`data.json`) generated from the NATS RSS feeds.
